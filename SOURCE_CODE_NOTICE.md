# Source Code Notice

This repository is a public engineering and product case study for Swimtopia.

The production source code is proprietary and is not published here.

The codebase remains private because:

1. Swimtopia is being developed with future commercialisation in mind.
2. My agreement with the club does not permit publication of the production source code.

This repository therefore focuses on:

- architecture;
- engineering decisions;
- deployment model;
- selected operational challenges;
- anonymised product screenshots;
- anonymised example outputs.

The repository must not contain:

- production credentials or secrets;
- private keys or certificates;
- athlete or user personal data;
- production hostnames;
- internal network topology;
- Active Directory structure;
- security-sensitive Cloudflare configuration;
- private API credentials.

All screenshots and reports included here should use anonymised or synthetic data.
